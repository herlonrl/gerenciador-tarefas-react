# Gerenciador de Tarefas React

Projeto simples de gerenciamento de tarefas desenvolvido com React. Permite adicionar, marcar como concluída e remover tarefas, ajudando no controle de atividades diárias.

## Funcionalidades

- Adicionar novas tarefas
- Marcar tarefas como concluídas
- Remover tarefas concluídas ou em andamento
- Interface simples e responsiva

## Tecnologias

- React
- JavaScript
- HTML
- CSS

## Como executar

1. Instale as dependências:

```bash
npm install
```

2. Inicie o servidor de desenvolvimento:

```bash
npm start
```

3. Abra o navegador em:

```bash
http://localhost:5173/
```

## Estrutura do projeto

- `src/` - código fonte do aplicativo
- `public/` - arquivos públicos
- `README.md` - documentação do projeto

## Observações

Este projeto pode ser usado como base para adicionar mais funcionalidades, como filtros, persistência local e edição de tarefas.
